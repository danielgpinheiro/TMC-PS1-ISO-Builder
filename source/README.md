[agbplay](https://github.com/ipatix/agbplay)'s sequencer (ipatix and contributors), licensed under the LGPL-3.0
([../licenses/LGPL-3.0.txt](../licenses/LGPL-3.0.txt), which adds to [../licenses/GPL-3.0.txt](../licenses/GPL-3.0.txt)).
It is the exact source built into `bin/files/TMCPS1.EXE` (TMC-ps1 port at commit `6020bf9f`).
